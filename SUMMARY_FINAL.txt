### STOP BOT:

**Dari Telegram (Owner only):**
```
/stopbot
```

**Dari terminal:**
```bash
kill $(cat bot.pid)
```

**Force kill semua:**
```bash
pkill -9 -f 'python.*bot.py'
```

### START BOT:

```bash
python3 bot.py 2>&1 &
echo $! > bot.pid
```

### RESTART BOT:

```bash
kill $(cat bot.pid) && sleep 2 && python3 bot.py 2>&1 &
echo $! > bot.pid
```

### CEK STATUS:

```bash
# Cek PID
cat bot.pid

# Cek health
curl localhost:8000/health

# Cek process
ps aux | grep 'python.*bot.py' | grep -v grep
```
